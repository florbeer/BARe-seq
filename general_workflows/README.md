# General Workflows

This folder contains scripts for analysis of BARE-seq data in R.

It intends to provide a general workflow that can be applied to different experiments and/or samples.

There are some lines of code that need to be adjusted, based on the experiment being analyzed. These lines inclue importing raw or processed data, or setting up sample names, library names, conditions, etc.


    
### Brief description of the scripts

-   R01_InitialProcessing.R

Checking quality controls (i.e. sequences and barcodes detected per library, library size, etc)

Relevant plots

Annotating estimates and filtering information into data frames. This part uses the outputs generated by `R02_NBFit_Exe.R` and `R03_ProfLik_Exe.R` scripts

-   R02_NBFit_Exe.R

Executable file to run in bash mode (with RScript), instead of an iterative RStudio session

Parameter inference by using the 0-inflated Negative Binomial model

Estimation of hessian matrices (for standard deviation), Kolmogorov Smirnov test computation

-   R03_ProfLik_Exe.R

Executable file to run in bash mode (with RScript), instead of an iterative RStudio session

Computing Profile Likelihood and 95% confidence intervals of the estimated parameters

-   R04_Motif_Analysis_STAPseq.R

Analysis of the promoter libraries (STAPseq)

Motif analysis by estimating the fold change when comparing motif-containing- vs motif-non-containing sequences

The first section shows an example with one dataset, and the second section an example with several datasets
   
-   R04_Motif_Analysis_STARRseq.R

Analysis of the promoter libraries (STARRseq)

Motif analysis by estimating the fold change when comparing motif-containing- vs motif-non-containing sequences

-   R05_LinearRegression_STAPseq.R

Comparison of multiple models for linear regression, together with the Fold Change approach (presented in `R04_Motif_Analysis_STAPseq.R` script)

It includes analysis of multiple datasets at a time
